# 1. 修正版分钟时间线

## 1.1 医疗与演出定义

为了避免“使用喷雾五分钟后死亡”的漏洞，案发阶段必须严格区分以下状态：

- **早期症状**：口周异常、恶心、心悸、胸部不适；人物仍清醒并能说话。
- **恶化**：心律明显紊乱、血压下降、站立困难；仍未死亡。
- **倒地**：意识丧失或循环崩溃，触发呼救。
- **抢救**：温如素实施心肺复苏、除颤及支持治疗；此时不能叙述为已经死亡。
- **死亡确认**：持续抢救失败后，由温如素确认死亡时间。

急救喷雾在所有叙事与 UI 中统一称为：

> 沈慈云个人处方的舌下定量急救喷雾。

不出现真实药品品牌、毒物配制方法或可复现剂量。

# 2. 喷雾替换完整犯罪链

## 2.1 沈仪真为什么能够接触喷雾

沈慈云的喷雾是个人处方的舌下定量急救喷雾，平时固定放在手袋内袋。案发当晚 23:00 原定进行医疗转移，转移协议要求：

- 核对所有随行处方药；
- 拍摄药品正反面与序列号；
- 把常用药与备用药分别登记；
- 将备用药装入转移急救包。

17:20 温如素拒绝为沈仪真出具“绝对不适宜转移”证明后，沈慈云反而命令沈仪真负责完成转移物品清单，理由是她一直替妹妹管理出行事务。

18:29—18:38，沈仪真因此获得以下合法接触条件：

1. 沈慈云把手袋和药柜钥匙交给她；
2. 何清和在书房处理转移文件；
3. 温如素在西翼整理沈意舒病历；
4. 沈慈云在相邻房间接听道路确认电话；
5. 药品整理区的门禁显示这一时间段只有沈仪真进入。

她不是秘密潜入药柜，而是利用了别人赋予她的“保护者权限”。

## 2.2 为什么可以提前替换

案发前三周，沈仪真开始准备逃离计划。她以“为沈慈云补领旅行备用药”为理由，签收过一支同外形、同规格的备用喷雾装置。签收行为本身合法且不起眼。

在法律撤销、医学异议、逃离计划和公开威胁相继失败后，她于案发日 18:18 确认沈慈云仍会执行 23:00 转移。18:29 开始药品盘点时，她已经带着事先被篡改的同型装置。

18:35，她不是重新灌装现场喷雾，而是完成整支装置替换：

- 正常处方喷雾：序列号 `CY-S17`，喷嘴帽有一道旧划痕；
- 被篡改喷雾：外形近似，属于同型备用外壳，序列号与处方登记不符；
- 两支装置的区别只有在放大盘点照片、核对序列号和旧划痕后才成立。

锁稿文本不得描述毒物制备步骤、剂量或装填方法。

## 2.3 原喷雾去向

沈仪真把正常喷雾 `CY-S17` 放入自己准备的逃离医疗包。

她对外可以解释为：

> “我以为那是需要随车携带的备用药，所以先装进了包里。”

这一解释在第三章仍然合理，因为：

- 她确实长期负责药物收纳；
- 玩家尚未证明茶室里使用了另一支喷雾；
- 她的逃离医疗包中还有大量为沈意舒准备的正常药物。

第五章核对序列号后，玩家才发现：

- `CY-S17` 才是沈慈云登记在册、当天 16:12 仍使用过的个人喷雾；
- 它在死亡时不在沈慈云手袋，而在沈仪真的私人逃离包；
- 这意味着茶室中 20:57 使用的必然是另一支替换装置。

## 2.4 被替换喷雾去向

21:19 沈仪真进入茶室后取走被篡改喷雾。

21:55，她进入原定 23:00 离开静园的转移车辆，把喷雾藏入硬壳医疗废弃物盒。她预计：

- 车辆离开后，废弃物盒会随医疗垃圾统一处理；
- 即使盒子被发现，也会被误认为抢救耗材；
- 暴雪会延迟而不是彻底阻止车辆离开。

22:34 道路完全封闭，车辆没有离开。凶器因此仍留在暴雪山庄封闭范围内。

## 2.5 死亡前替换如何被唯一证明

喷雾定罪不得依靠“拿过药”“袖口残留”或“清洁布”。完整证明由六部分组成：

### A. 18:29 与 18:38 的两张盘点照片

- 18:29 照片中，手袋旁是登记喷雾 `CY-S17`，旧划痕可见。
- 18:38 照片中，手袋内已经变成无旧划痕的同型装置。
- 两张照片由转移表单自动上传并带设备时间戳，不可事后替换。

### B. 唯一进入者

18:29—18:38 药品整理区门禁只有沈仪真一人。沈慈云、温如素、何清和均有独立设备或目击记录证明身处别处。

### C. 原处方喷雾

登记喷雾 `CY-S17` 最终在沈仪真的私人逃离医疗包中被找到，剩余剂量与当天 16:12 使用记录吻合。

### D. 回收的被篡改喷雾

车辆医疗废弃物盒中回收另一支同型喷雾：

- 内部检出全案唯一高浓度乌头来源；
- 载体辅料与沈慈云口腔拭子、杯沿残留一致；
- 其装置序列与沈仪真此前签收的备用装置记录相连。

### E. 案后转移行为

门禁和车辆访问记录证明沈仪真：

- 21:19 首先进入茶室；
- 21:55 独自进入转移车辆；
- 进入前后都没有合法医疗废物需要放入车辆。

### F. 排他性结论

玩家必须组合：

`盘点照片变化 + 唯一进入窗口 + 原喷雾在私人包中 + 毒喷雾实物回收 + 口腔/杯沿辅料一致 + 案后车辆访问`

才能提交：

> 沈仪真在死亡前替换了喷雾，并在死亡后试图转移凶器。

任何一项单独证据都不足以定罪；六项组合后，没有其他角色同时满足替换机会、原物占有、凶器转移和独立动机。

# 4. 固定沈意舒真实身份

## 4.1 原身份

- **原姓名**：沈小鹿
- **案发时年龄**：九岁
- **生母**：沈慈宁，沈慈云的妹妹
- **生父**：许廷川
- **姓氏来源**：沈小鹿随母姓
- **与沈慈云关系**：亲姨母与受监护外甥女
- **与沈仪真关系**：生物学上的亲表姐妹；十二年来在社会关系中以亲姐妹身份共同生活，沈仪真作为姐姐照料沈意舒
- **新姓名**：沈意舒；栖湖案后保留“沈”姓，名字、出生资料、监护关系与身份档案被重新建立
- **儿童选择的验证边界**：第二章只能看到文件声称保护安排符合儿童意愿；九岁的沈小鹿是否主动参与选择“沈意舒”，必须到第五章通过录音与附页验证
- **表面登记**：沈慈云的法定女儿、沈家次女
- **成年选择权**：她可以继续使用“沈意舒”、恢复“沈小鹿”，或选择新的名字

因此，“不存在的女儿”有三层含义：

1. 沈慈云在生物学上没有名为沈意舒的次女；
2. 法律文件把沈小鹿与沈意舒写成了无法自然接续的两个身份；
3. 成年后的沈意舒被迫在别人规定的名字之间选择，而她本应拥有继续使用、恢复或重新命名的权利。

## 4.2 十二年前事件：栖湖别墅案

### 事件前

沈慈宁长期遭受许廷川的家庭暴力与经济控制。许廷川利用人脉压下两次报警，并掌握沈慈宁个人财产。

沈慈云已经知道妹妹处境危险，却曾劝她：

> “先不要把事情公开，等家里安排好。”

她的理由是避免许廷川立即反击、保护沈家声誉和等待更稳妥的法律方案。这个延迟导致沈慈宁在最需要帮助时没有离开。

### 案发夜

沈慈宁准备带九岁的沈小鹿离开栖湖别墅，并把家暴记录与财务材料交给沈慈云。

当夜双方发生冲突。沈小鹿目睹父亲对母亲施暴，随后沈慈宁从楼梯平台坠落死亡。现场被许廷川处理成意外跌落。

沈小鹿躲在储物间，用母亲留下的电话联系沈慈云。沈慈云赶到后没有立即把孩子交回许廷川，而是将她送到温如素所在的私人诊疗点。

### 旧案为何没有立即解决

- 现场被破坏；
- 关键家暴与财务材料缺失；
- 沈小鹿处于急性创伤状态，最初证词破碎；
- 许廷川仍是法律上的父亲和第一顺位监护人；
- 临时安置地点曾因内部信息泄露被许廷川的人找到；
- 正常监护程序无法在短时间内保证孩子不被带走。

这使“立即隐藏身份”在当时具有真实的救援必要性，但不使十二年的持续封存天然正当。

## 4.3 沈慈云的行为与责任

### 她做对的事

- 赶到栖湖别墅并带走沈小鹿；
- 承担隐藏证人、对抗许廷川和安置孩子的风险；
- 给沈小鹿安全住所；
- 尊重孩子当时“不被找到、不再听见旧名”的请求；
- 在最初数年提供真实而持续的生活照料。

### 她必须承担的旧案责任

- 在案发前已知家暴，却以等待更安全方案和维护家族声誉为由劝妹妹延迟公开；
- 救援后选择非法身份替换，而没有持续推动可复核的正式保护程序；
- 旧案材料后来具备重新调查条件时，她优先维护既有身份秩序；
- 许廷川失去直接监护能力后，她仍不允许沈意舒查看完整文件；
- 沈意舒成年后申请调阅原档并重新决定身份使用方式，她命令何清和撤回；
- 案发前三周旧案再次被查询时，她不先告知沈意舒，而直接启动 23:00 强制转移。

她的核心不是“假装救人”，而是：

> 她十二年前做对了一次，于是相信自己以后永远有权决定。

## 4.4 温如素的行为与责任

### 她做对的事

- 记录沈小鹿身上的旧伤与急性创伤反应；
- 拒绝许廷川直接带走仍在治疗中的孩子；
- 在最初阶段建议隔离施害者和媒体；
- 保存了没有被沈家完全销毁的医学原始记录。

### 她必须承担的责任

- 将“急性期暂缓刺激”延长为长期限制知情；
- 没有定期重新评估沈意舒是否具备读取病历和旧案的能力；
- 多次以防止创伤复发为由，只向沈慈云说明风险，不直接向成年沈意舒说明；
- 案发后先公开杯中乌头，扣下完整毒理，以保护沈意舒免于立即被定罪；
- 她没有伪造或销毁数据，但选择性披露妨碍了玩家理解死亡机制。

## 4.5 何清和的行为与责任

### 他做对的事

- 在正常监护程序失效、安置点泄露的紧急阶段，阻止许廷川立即取得孩子；
- 保存原身份与儿童请求附页，使沈小鹿没有在法律档案中被彻底消失；
- 将可追踪资料限制在极少数人范围内。

### 他必须承担的责任

- 通过虚假监护、户籍和出生材料，把沈小鹿登记为沈慈云的法定女儿、沈家次女沈意舒；
- 把紧急保护措施写成缺少终止条件的长期安排；
- 将九岁儿童的请求当作持续授权；
- 沈意舒成年后要求查看原档并重新决定身份使用方式时，服从沈慈云指令中止程序；
- 案发后再次封存材料，重复了十二年前“先替她决定”的模式。

## 4.6 为什么当时需要身份封存

身份封存的当时必要性由四个事实共同建立：

1. 许廷川拥有法律监护身份，且被合理怀疑与沈慈宁死亡有关；
2. 临时安置地点已经发生过一次信息泄露；
3. 九岁的沈小鹿是潜在目击证人，存在被带走、胁迫或改写证词的风险；
4. 正常司法和监护程序无法在当夜提供即时保护。

身份封存只在以下范围内可能获得过沈小鹿当时的意愿支持；第二章不能确认意愿形成过程，第五章才验证：

- 暂时不用原姓名；
- 暂时不被许廷川找到；
- 急性创伤期不反复追问案发细节。

她从未同意：

- 成年后仍不能查看自己的文件；
- 永久放弃恢复或更换身份；
- 由沈慈云决定她住在哪里；
- 由温如素决定她能知道什么；
- 由何清和决定她的童年请求永不失效；
- 由沈仪真决定她必须离开或必须被谁保护。

## 5.2 推理公平性复审

### 第一章是否能破解完整答案

玩家仍可能猜中“沈仪真 + 喷雾”，但无法在第一章证明：

- 原喷雾在哪里；
- 茶中乌头如何形成；
- 沈意舒加入的是何种物质；
- 凶器为什么仍留在静园。

完整答案必须经过：

`第一章异常 → 第二章盘点与身份 → 第三章失败方案 → 第四章毒理路径 → 第五章装置与序列闭环`

**结论：通过。**

### 关键证据是否提前出现、最终回收

- 物理真相的原始材料最迟在第二章出现；
- 第四章新增的是检验结果与正确关联，不是凭空新增凶器；
- 第五章新增的是打开已知容器、核对已知序列和恢复已知录音，不是突然出现外部证人。

**结论：通过。**

## 5.3 人物合理性复审

### 沈仪真

她不是没有其他选择。她仍可以接受沈意舒拒绝、继续法律争取或允许她面对风险。她杀人，是因为无法接受妹妹选择一个不需要自己的未来。

四次失败记录解释她如何把自己逼入“只剩杀人”的主观困境，却不把杀人包装成客观必要。

**结论：动机成立，仍值得理解，不被洗白。**

### 沈意舒

她确实下药、撒谎并制造风险；同时：

- 镇静剂不是胸闷的即时原因；
- 她设置并执行求助提醒；
- 她参与抢救；
- 她最终主动承认并接受后果。

**结论：共情成立，成长成立，不是纯受害者。**

### 沈慈云

她的救援是真实的；案发前延迟妹妹求助、非法身份替换、成年后撤回申请、强制转移也都真实。

最终录音只证明她十二年前曾尊重一次选择，反而强化她后来为什么更难停止控制。

**结论：没有过度洗白，旧案责任明确。**

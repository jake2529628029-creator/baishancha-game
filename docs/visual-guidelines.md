# 《白山茶遗嘱》V0.3 视觉规范

## 视觉基调

- 气质：冷静、克制、档案感；避免恐怖游戏式血腥与高饱和警示色。
- 主色：墨绿黑 `#0B1210`、档案绿 `#17211E`。
- 文字：旧纸白 `#E9E3D7`、次级灰绿 `#9AA49D`。
- 强调：旧金 `#BEA169`，只用于可交互焦点、已确认状态和关键编号。
- 错误：暗陶红 `#A77A69`；正确：冷苔绿 `#86A393`。

## 图片规格

| 用途 | 比例 | 建议源尺寸 | 展示方式 |
| --- | --- | --- | --- |
| 现场证物照片 | 16:9 | 1600×900 以上 | cover，焦点由 JSON 指定 |
| 文件扫描件 | 3:4 | 1200×1600 以上 | contain |
| 人物档案照（后续） | 3:4 | 900×1200 以上 | cover |
| 材料缩略图 | 4:3 | 640×480 以上 | cover |

- PNG 用于需要无损辨识的证物；普通照片优先 WebP。
- 单张运行时资源建议不超过 1.5 MB。
- 热点坐标按原始画面百分比保存，证物图不使用会改变构图的二次裁切。

## 排版

- 标题：宋体/衬线字体，常规字重，强调文学感与家族档案感。
- 操作、编号、状态：系统无衬线字体，便于快速扫描。
- 正文行高 1.65–1.95；单段阅读宽度不超过 46rem。
- 层级依靠字号、留白和细线建立，不依赖大面积色块。

## 组件与交互

- 面板使用直角、1px 低对比描边；不使用圆润卡片或玻璃拟态泛光。
- 所有可点击证据必须有悬停、键盘焦点和选中状态。
- “材料、观察、证据、推理”分别使用固定编号和标签，不用颜色单独传达含义。
- 正确反馈不等于“案件真相”；文案统一使用“阶段性结论”。
- 错误推理可撤回，但会进入章节结算记录。
- 动画仅限 120–180ms 的颜色与边框过渡，尊重减少动态效果设置。
